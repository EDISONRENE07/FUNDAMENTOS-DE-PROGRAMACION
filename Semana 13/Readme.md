Nombre del proyecto: Calcular el total de una compra
----------------------------------------------------
Objetivo del programa
-----------------------------------------------------------------
Calcular el valor total de una compra a partir del precio de un producto y la cantidad que compra el cliente, utilizando una función en Python.

El programa:

Solicita al usuario el precio del producto.

Solicita la cantidad de productos.

Utiliza la función calcular_total() para multiplicar el precio por la cantidad.

Muestra en pantalla el total que debe pagar el cliente.
